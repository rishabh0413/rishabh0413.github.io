# Personal Portfolio Website 🚀

Welcome to the repository of my personal portfolio website. This project showcases my journey as a Web Developer, featuring my recent client projects, technical skills, and professional experience.

## 🔗 Live Demo
[View Live Portfolio Here](https://rishabh0413.github.io)

## 🛠️ Built With
- **HTML5:** Semantic and accessible structure.
- **CSS3 (Custom Variables & Grid/Flexbox):** Modern dark-theme UI with responsive bento-grid layouts, glowing hover effects, and smooth transitions.
- **Vanilla JavaScript:** Intersection Observer for high-performance scroll reveal animations and sticky navbar logic.

## ✨ Features
- **Bento Grid Architecture:** Clean, compartmentalized UI for skills and about sections.
- **Performance Optimized:** No heavy external libraries; pure native CSS and JS.
- **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens.
- **Interactive Elements:** Direct `tel:` and `mailto:` links, dynamic hover states, and smooth scroll behaviors.
